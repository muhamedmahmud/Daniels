# 🧑‍🎨 Daniels – Personal Portfolio Website

**Daniels** is a modern and elegant personal portfolio website template. Built using **HTML**, **CSS**, **Bootstrap**, and **JavaScript**, it showcases personal details, services, portfolio items, testimonials, and contact information in a clean, responsive design.

---

## 📸 Demo

🌐 [Live Demo](https://muhamedmahmud.github.io/Daniels/)  
📂 [GitHub Repository](https://github.com/muhamedmahmud/Daniels)

---

## 🚀 Features

- 🖼️ Smooth scrolling navigation  
- 📱 Fully responsive and mobile-friendly  
- 🧑‍💼 About, Services, Portfolio, Testimonials, and Contact sections  
- ✉️ Contact form with validation  
- 🎨 Styled using Bootstrap 5 for consistency and speed  
- 🔗 Social media integration  
- 💡 Animated counters and skill progress bars

---

## 🛠️ Technologies Used

| Technology     | Description                        |
|----------------|------------------------------------|
| HTML5          | Page structure                     |
| CSS3           | Custom styles                      |
| Bootstrap 5    | Responsive grid and components     |
| JavaScript     | DOM interaction and animations     |
| Font Awesome   | Icons                              |
| jQuery         | Used for some interactive features |
| WOW.js         | Scroll reveal animations           |
| Typed.js       | Typing animation in header         |
| Owl Carousel   | Testimonials carousel slider       |
